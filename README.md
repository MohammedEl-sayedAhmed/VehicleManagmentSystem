# Vehicle Rental Management System

## Overview

The Vehicle Rental Management System is a software application designed to streamline the operations of a vehicle rental business. This system enables users to efficiently manage vehicles, customers, and rental transactions. By automating various processes, the system aims to reduce manual work, minimize errors, and enhance the overall customer experience in vehicle rental services.

## Features

- **Customer Management**: Handle customer registration, store customer details, and track rental history.
- **Vehicle Management**: Add, update, delete, and view vehicles available for rent.
- **Rental Transactions**: Record all aspects of the rental process, including duration, extra fees, and renter's insurance.
- **Payment Processing**: Log various payment methods and ensure smooth transaction processes.
- **Sales Reports**: Generate and view sales reports based on rental transactions.

## Technologies Used

- Java
- Swing (for GUI)
- Serialization (for data persistence)
- Java Collections Framework

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- An IDE (e.g., IntelliJ IDEA, Eclipse) or a text editor
- Git (optional, for version control)

### Steps to Run the Project

1. **Clone the Repository**:
   Open your terminal and run the following command to clone the repository:

   ```bash
   git clone https://github.com/MohammedEl-sayedAhmed/VehicleManagmentSystem.git
   ```

2. **Navigate to the Project Directory**:
   Change your directory to the project folder:

   ```bash
   cd VehicleManagmentSystem
   ```

3. **Open the Project in Your IDE**:
   Open the project in your preferred IDE. If you are using IntelliJ IDEA, you can simply open the project folder.

4. **Compile the Project**:
   Make sure all the necessary dependencies are included. If you are using an IDE, it should handle the compilation automatically.

5. **Run the Application**:
   Locate the `Main` class (or the class with the `main` method) in the `gui` package and run it. This will launch the Vehicle Rental Management System.

6. **Using the Application**:
   - Use the main window to navigate through different functionalities such as managing vehicles, handling customers, and processing rentals.
   - Follow the prompts to add vehicles, register customers, and rent vehicles.
